# Privacy Policy — SpotDock

**Last updated: November 26, 2026**

SpotDock does **not collect, store, or transmit any personal data**. There are no
analytics, no telemetry, no accounts, and no tracking of any kind.

- All settings are stored locally on your device (`%APPDATA%\SpotDock\`).
- Track information (title, artist, album art) is read locally from the Windows
  media session (SMTC) for Spotify Desktop and, if enabled, from the local
  `SpotDock Bridge` WebSocket (`127.0.0.1:45219`) for `open.spotify.com`.
- Album artwork URLs provided by Spotify Web are downloaded directly to display
  the cover art locally.
- Automatic update checks are disabled by default; when enabled in custom builds,
  only GitHub's public releases API is queried (no identifying information is sent).

This is an independent open-source project, not affiliated with Spotify AB.
